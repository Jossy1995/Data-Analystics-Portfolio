# 👟 Zen EliteStride Sales Dashboard

## 📊 Project Overview
This project analyzes shoe sales data for Zen Analytis across multiple countries, brands, and product categories. Using **Excel** and Sales analysis for Tech4Dev Women Initiative using **Power BI**, the dataset was cleaned, modeled, and visualized to uncover insights into sales performance, profitability, and customer preferences.

## 📂 Repository Contents
- **Zen EliteStride Sales Dashboard.xlsx** → Raw dataset containing product details, sales transactions, and pricing information.  
- **Tech4Dev Sales Dashboard.pbix** → Power BI dashboard file with interactive visualizations.  
- **images/** → Screenshots of dashboards for quick preview.  
- **README.md** → Documentation explaining the project.  

## ⚙️ Tools & Skills Demonstrated
- **Excel**: Data cleaning, transformation, and preparation.  
- **Power BI**: Data modeling, DAX measures, and interactive dashboards.  
- **Visualization**: Sales trends, KPIs, regional performance, and product category analysis.  

## 📈 Key Insights
- Identified **top-performing brands** across regions (Clarks, Nike, Zara, Timberland, Steve Madden).  
- Analyzed **unit price vs. unit cost** to highlight profitability margins.  
- Segmented product categories (Formal, Casual, Utility, Open) to compare demand and sales volume.  
- Built **dynamic dashboards** enabling faster decision-making for sales and marketing teams.  

## 🚀 How to Use
1. Download the repository files.  
2. Open **Zen EliteStride Sales Dashboard.pbix** in Power BI Desktop.  
3. Explore interactive dashboards (filters by country, brand, category, etc.).  
4. Review **Excel dataset** for raw data structure.
